# 艺术字字体生成

入口：`★AlloyFramework★/UI/艺术字字体生成`。

## 新建

1. 选择 UGUI Text 或 TextMeshPro，填写字体名称、输出目录。
2. 选择或拖入图片文件夹，会自动扫描 PNG/JPG/JPEG。支持 Project 和系统文件夹，输出必须在 Assets 子目录。
3. 文件名使用单字（`0.png`、`胜.png`）或码点（`U+002F.png`）。其他文件名可手动映射，或输入一串字符按列表顺序批量映射，例如 `1234567890`。
4. 默认按图片尺寸自动计算字号、基线与行高；仅需按需调整字距或等宽步进。手动度量放在高级排版中。
5. 点击“校验并预览”，输入实际文案检查缺字、基线与间距，再“一键生成字体”。
6. 将 Font / Font Asset 配置到组件，或选中匹配类型的组件点击“应用到选中组件”。应用支持撤销，不修改文本内容。

TMP 使用官方 `TextMeshPro/Bitmap Custom Atlas`，Text 使用 `UI/Default`。不新增 shader。未导入 TMP 基础资源时，面板提供官方资源包的导入入口。

## 更新与追加

选择“更新已有字体”，拖入上次生成的 `.artfont.asset`。源目录、字符参数可继续修改。
也可以双击 `.artfont.asset`，直接在面板中打开对应字体。

- “扫描并追加字符”：保留全部已有行，追加新图片。
- “重新扫描”：移除目录中已不存在的图片；保留文件路径匹配的手动映射和排版参数。
- “重新生成”：原地更新字体、图集、材质和配置，保留 GUID 与组件引用。类型、名称与输出位置锁定，避免意外覆盖另一套字体。

追加依赖源图片和生成配置：先把新图片放进源文件夹，再扫描追加并重新生成整张图集与字符表。
重打包可以改变图集内部 UV，但组件引用的字体、图集和材质 GUID 不变，业务代码无需调整。

同名新建会被拒绝；输出文件被手动移动或删除时会提示修复。输入和容量校验先于资产写入，生成异常时回滚本次产物文件。

## 度量规则

- 字形宽高取原图完整尺寸，不裁透明边，不旋转或缩小原图。JPG 没有透明通道，原有背景会保留；需要透明效果时使用透明 PNG。
- 默认图片底边对齐基线。偏移 X/Y 单位为设计像素，Y 向上为正。
- 步进大于 0 为单字覆盖；0 使用“图片宽度或等宽宽度 + 额外字距”。
- 字形间距与图集隔离区不同；边缘扩展不计入字形尺寸。
- 隔离区保留边缘 RGB，Alpha 为透明，兼容 TMP 官方 Bitmap 材质的额外采样范围。
- 自动添加空格，可单独配置宽度；不支持普通字体替代缺失的艺术素材。
- Legacy Text 仅接受 BMP 字符；TMP 支持单个 Unicode 标量，包括代理对。

产物包括字体、RGBA PNG、共享材质和编辑器配置。配置不需要加入运行时资源包，运行时只需要字体与材质/图集依赖。源 PNG 保持原导入设置，生成图集使用无压缩、无 MipMap、关闭 Read/Write 的设置。

业务保持 `text.text = "战力12345"`。字号、颜色、Rich Text 与材质覆盖属于展示配置；一键应用会设置白色、设计字号、正常字体样式并关闭自动字号和富文本。
